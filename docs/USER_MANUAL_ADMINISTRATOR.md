# Administrator User Manual - v1.0

The administrator configures accounts, departments, courses and enrolments. Administrators do not perform marking or moderation.

## Sign in

Start the application, enter your LMS username and password, and choose the Administrator role when prompted. Use a named account in normal operation; change or disable demonstration accounts after installation.

## Main menu

| Option | Use |
|---|---|
| 1. Create user | Create a Lecturer, Student, Head of Department (`HOD`) or Administrator account. Assign a department where applicable. |
| 2. Edit/activate/deactivate user | Select a user ID, update account details and active status, or set a new password. Leave the password blank to retain it. |
| 3. List users | Review user IDs, usernames, role and active status. |
| 4. Create department | Add a department before creating its courses or HoD accounts. |
| 5. Create course | Enter a unique course code/title and select its department. |
| 6. Edit course | Update a course's code, title or department. |
| 7. Assign lecturer to course | Enter the lecturer user ID and course ID. |
| 8. Enrol student in course | Enter the student user ID and course ID. |
| 9. List courses | Review courses visible to the administrator. |
| 10. Edit department | Rename the selected department. |
| 0. Log out | Return to the login screen. |

## Recommended setup sequence

1. Create departments.
2. Create each course and assign it to the correct department.
3. Create lecturer accounts and assign lecturers to courses.
4. Create HoD accounts and assign each to the appropriate department.
5. Create student accounts and enrol each student in the appropriate courses.
6. Verify account status and course assignments before users begin work.

The application rejects duplicate course assignments and enrolments, invalid role actions, and HoD accounts without a department. Keep a secure record of issued initial passwords using the school's approved process, and require users to protect them. Use **Edit/activate/deactivate user** to deactivate leavers rather than reusing their accounts.
