# Lecturer User Manual - v1.0

Lecturers work only with their assigned courses. The Head of Department controls moderation and release of marked results.

## Main menu

| Option | Use |
|---|---|
| 1. List my courses | Check courses assigned to your account. |
| 2. List my assignments | View assignment deadlines, effective deadlines and submission/marking counts. |
| 3. Create assignment | Choose a course, enter title, local deadline (`YYYY-MM-DD HH:MM`), maximum mark and optionally a supported brief file. The brief is copied into managed storage. |
| 4. Grant/update extension | Enter the assignment ID, student user ID, revised deadline and reason to grant/update an individual student's extension. The revised deadline must be later than the original. |
| 5. View and mark submissions | Choose an active submission, optionally open the student document and brief, then enter the raw mark and written feedback. Revised marks require a reason. The result remains hidden until the HoD releases it. |
| 6. Open an assignment brief | Select an assignment and open its attached brief if present. |
| 0. Log out | Return to the login screen. |

## Marking workflow

1. Use **2. List my assignments** to identify the assignment and check its counts.
2. Use **5. View and mark submissions**, select the submission ID, and review the work and brief before marking.
3. Enter a raw mark no greater than the assignment maximum and useful written feedback. A revision to an existing mark requires a reason.
4. Tell the HoD the submission is ready for moderation. A lecturer's mark is not visible to the student until the HoD approves/moderates and releases it.

Assignment and submission documents support PDF, DOC/DOCX, ODT, RTF, TXT/Markdown, PPT/PPTX, XLS/XLSX and CSV, up to 25 MB. Submit a clear reason when granting an extension. v1.0 supports individual extensions; class-wide extensions are introduced in v1.1.
