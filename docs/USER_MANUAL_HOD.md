# Head of Department User Manual - v1.1

The Head of Department (HoD) reviews lecturer-marked work for the HoD's department, records moderation decisions, controls release, and inspects mark history. The HoD cannot access another department's work.

## Main menu

| Option | Use |
|---|---|
| 1. List departmental courses | Review courses within your department. |
| 2. View department assignments and submission counts | Inspect assignment details and active/marked submission counts. |
| 3. Moderate marked work | Review lecturer-marked submissions. Optionally open the student's document and assignment brief. Approve the mark unchanged or enter a revised final mark and reason. Then choose whether to release immediately. |
| 4. Release moderated work | Release a moderated result that was not released during option 3. |
| 5. View mark audit history | Inspect the department's recorded mark changes, actor, old/new values and reason. |
| 0. Log out | Return to the login screen. |

## Moderation and release

1. Select **3. Moderate marked work**. This list contains lecturer-marked submissions awaiting moderation; work already moderated but not released is not in this queue.
2. Select a submission ID. Review the student's submission and assignment brief before deciding.
3. Press Enter at the revised-mark prompt to approve the lecturer's mark unchanged. Otherwise enter a valid final mark (no greater than the assignment maximum) and provide the reason for the change.
4. Confirm immediate release, or choose **4. Release moderated work** later. Until release, marks and feedback remain hidden from the student.
5. Use **5. View mark audit history** when checking the recorded moderation trail.

If no submissions appear, ask the lecturer to mark the work first. Moderation is limited to the department associated with your HoD account.
